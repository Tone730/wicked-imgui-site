# Wicked Imgui — the free stack

Everything below has a **$0/month entry option**. "Free" usually means no monthly fee with a per-sale cut — that is the right trade for a project that has not sold its first copy yet.

> ⚠️ **Correction to earlier advice:** Lemon Squeezy closed new signups on 16 Nov 2026 and stops processing all payments on **31 Mar 2027**. Do not build on it. Its team recommends Stripe Managed Payments; the free alternatives below are Polar, Payhip, Gumroad and Ko-fi.

## 1. Payments

| Provider | Monthly | Per sale | Handles tax/refunds | Notes |
|---|---|---|---|---|
| **Polar Starter** ⭐ | $0 | 5% + 50¢ | Yes — Merchant of Record | Built for software, subscriptions and license keys. Best direct replacement for Lemon Squeezy. |
| **Payhip Free** ⭐ | $0 | 5% + your Stripe/PayPal fee | EU/UK VAT (check their page for US/CA) | No product or revenue limits. Money lands in your own Stripe/PayPal. Free plan has all features. |
| **Gumroad** | $0 | 10% + 50¢ (+ processing) | Yes — Merchant of Record | Easiest launch, highest fee. 30% on Discover marketplace sales. |
| **Ko-fi** | $0 | 5% shop / 0% tips | No — you handle tax | Money goes straight to PayPal/Stripe. Gold ($12/mo) removes the 5%. |
| **GitHub Sponsors** | $0 | 0% platform fee | No | Recurring community support, not a product checkout. |
| **PayPal.me** | $0 | Standard PayPal fees | No | Simple fallback for buyers who refuse other processors. |
| Stripe Managed Payments | $0 | 3.5% + Stripe processing | Yes — Merchant of Record | Built by the ex-Lemon Squeezy team. Not free per sale, but no monthly fee and no tax admin. |

**Recommendation:** start with **Polar Starter** as the primary checkout (tax handled, license keys built in) and add **Payhip** or a **Ko-fi** tip jar as a second option. Put their URLs in `js/config.js`:

```js
checkout: {
  provider: 'Polar',
  note: 'Merchant of record · global tax handled · 5% + 50¢, no monthly fee',
  monthly: 'https://polar.sh/…/checkout/monthly',
  yearly:  'https://polar.sh/…/checkout/yearly',
  portal:  'https://polar.sh/…/portal',
},
alternatives: [
  { id: 'payhip', name: 'Payhip', note: 'Free plan · 5% + your processor', url: 'https://payhip.com/…' },
  { id: 'kofi',   name: 'Ko-fi',  note: 'Tips 0% · shop 5%',              url: 'https://ko-fi.com/…' },
],
```

Any provider with a URL shows up as a button on **Billing**. Empty URLs are hidden and the main Upgrade button stays in preview mode.

## 2. Download hosting

| Option | Free allowance | Notes |
|---|---|---|
| **GitHub Releases** ⭐ | No total quota, 1,000 assets/release, 2 GiB per file, unlimited bandwidth | Anonymous downloads, version history, stable URLs. Best starting point. |
| **Cloudflare R2** | 10 GB-month storage, 1M writes + 10M reads/month, **zero egress fees** | Use a custom domain in production; the `r2.dev` URL is rate-limited for testing. |
| **itch.io** | Free to host | Indie-friendly, has its own audience. Takes a cut on paid downloads. |
| **SourceForge** | Free | Old but reliable, good for open-source mirrors. |

Set `js/release.js` → `file` to the full HTTPS URL of the uploaded asset. The Downloads page shows size and SHA-256 either way.

Upload `latest.json` and `latest.yml` beside the ZIP. They are generated by `tools\attach-release.ps1` and give you a **free self-hosted update feed** for both the dashboard and the app. Set `CONFIG.updates.baseUrl` here and bake the same URL into the app with `build.ps1 -UpdateFeedUrl`. No paid update service is needed.

## 3. Code signing

**Free option — SignPath Foundation:** free OV code signing for qualifying **open-source** projects. Requirements include an OSI-approved license with **no commercial dual-licensing**, a public maintained repo, an already-released binary, MFA for all maintainers, defined author/reviewer/approver roles, and a "Code signing policy" section on your site.

⚠️ Because Wicked Imgui has a paid Pro tier, you are likely **not eligible** if the code is proprietary or dual-licensed. If you genuinely open-source the whole codebase under one OSI license (and monetise support/hosting instead), you may qualify. Apply at https://signpath.org/apply.html and add the required policy page.

**If not eligible:** there is no legitimate free Authenticode certificate for closed-source software. Budget roughly **$250–$700/year** for an OV/EV certificate from DigiCert, Sectigo or GlobalSign and sign with `signtool`. Until then, publish the SHA-256 (already done) and accept that Windows may warn users.

## 4. License keys

| Option | Cost | Notes |
|---|---|---|
| **Included server** (`server/`) ⭐ | $0 | Signed keys, 3-device enforcement, no dependencies. 12/12 smoke tests pass. |
| **Keygen Dev** | $0 | 100 active licensed users, 10 product releases, full licensing API. https://keygen.sh/pricing/ |
| **Keygen CE** | $0 | Self-host the community edition. https://github.com/keygen-sh/keygen-api |
| **Keygate** | $0 | Open-source self-hosted licensing with subscriptions, trials and Stripe. https://github.com/tabloy/keygate |

Connect the included server with:

```js
// js/config.js
license: { mode: 'remote', url: 'http://127.0.0.1:8787' },
```

Then Redeem validates and activates the key server-side via `js/license.js`.

## 6. Recommended zero-cost launch stack

1. **Site:** this folder on Cloudflare Pages (or GitHub Pages).
2. **Portable build + update feed:** GitHub Releases hosts the ZIP and the generated `latest.json` / `latest.yml`; sign a future installer if eligible via SignPath, otherwise publish the SHA-256.
3. **Checkout:** Polar Starter primary, Payhip + Ko-fi as alternatives.
4. **Licensing:** the included `server/` on a free Render/Railway service, or Keygen Dev.
5. **Support:** Discord + `wick777@engineer.com`.
6. **Analytics/errors:** Cloudflare Web Analytics + Sentry free.

Total monthly cost: **$0** until you have sales. Then the only unavoidable costs are a signing certificate (if not OSS-eligible) and whatever your payment provider takes per transaction.
