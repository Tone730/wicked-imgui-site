Help & FAQ

Everything you need to install, activate and use Wicked Imgui.

Still stuck? Email support, join the Discord server, or see our full contact details.

Where do I download the app?

From the Downloads page. Download the portable ZIP, extract it, and run Wicked ImGui Maker.exe — it starts as Wicked Local Pro, so no sign-in or license key is needed. Always check the SHA-256 shown next to the download; Get-FileHash .\WickedImgui-Portable-2.0.0.zip in PowerShell prints the hash of the file.

Which operating systems are supported?

Windows 10 and 11, 64-bit. DirectX 11 is required for the editor. The build is self-contained, so you don’t need to install .NET or a C++ runtime separately.

How do I activate my license?

The distributed build is already unlocked locally — there is nothing to activate. If you later connect a hosted account backend, sign in under Account in the app; your key is on the License page and can be pasted into the app for offline activation.

How many computers can I use?

A Free account can sign in on up to three computers. Pro accounts get the same three slots with commercial use and source export. Manage or sign out computers on the Devices page.

What’s the difference between Free and Pro?

The downloadable build starts as Wicked Local Pro with every feature unlocked: offline AI, C++/C#/Rust export, two-way code sync, custom code, all widgets and templates, and commercial use. The Billing plans describe optional hosted accounts, licensing and updates.

Can I use my own AI API key?

Yes. The app includes Wicked Local (offline), which needs no key or network, plus Google Gemini, AiHubMix, OpenRouter, NVIDIA, Ollama, Anthropic Claude and OpenAI if you enter your own key.

Does the app work offline?

Yes. The full-access build never needs a network connection — no sign-in, license server or AI key is required for local editing. When a self-hosted update feed is configured, the app can check it in the background; you can also check manually on the Downloads page.

How do I cancel or change my subscription?

Use Manage subscription on the Billing page. Cancelling keeps Pro until the end of the period you already paid for. For an invoice or refund question, email wickz77r@gmail.com. In this local preview there is no real checkout, so the button only shows a notice.

I forgot my password.

Use Forgot password? on the login page and we’ll email you a reset link. In preview mode no email is sent — accounts are stored only in this browser.

How do I delete my account?

Open Settings and use Delete account. You’ll be asked to enter your password to confirm. This cannot be undone.

Which payment providers can I use?

You can pay through any provider configured on the Billing page. Our free-first options all have no monthly fee: Payhip Free (5% plus your processor), Polar Starter (5% + 50¢, handles tax), Gumroad (10% + 50¢) and Ko-fi. GitHub Sponsors and PayPal.me are also available as alternatives. Checkout links are opened on the provider’s own secure site.

Is there a free way to sign the installer?

The SignPath Foundation gives free code signing to qualifying open-source projects, but paid dual-licensed software is normally not eligible. Closed-source builds need a paid OV/EV certificate. Either way we publish the SHA-256 of every release on the Downloads page so you can verify what you downloaded.

Is there a free license server?

Yes. This project includes a small, dependency-free license server under server/ that issues signed keys and enforces the three-device limit. Keygen also has a free Dev tier and a free self-hosted Community Edition.

Where can I host downloads for free?

GitHub Releases has no total storage or bandwidth quota for release assets (2 GiB per file), and Cloudflare R2 includes 10 GB of storage and free egress every month. Both are linked from the Downloads page once a release URL is set.

How do updates work?

Every build publishes latest.json and latest.yml beside the download. The app checks that self-hosted feed and verifies the published checksum; the dashboard shows the current channel and version and has a manual Check for updates button. The full history is on the Changelog page.
